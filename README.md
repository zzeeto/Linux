### 사용자 생성 및 계정 관리

#### 명령어 개요

**`which`** 명령어 경로 확인

ls
ls -al

**`alias`** ll =’ls -al’ 별명 붙여주는 명령어
**`unalias`** ll 별명 해제

echo $PS1
echo $**`PATH`** 명령어의 실행파일 위치를 저장해 놓은 환경 변수

ls = /usr/bin/ls

#### 도움말

**`man`** ls 리눅스 명령어들의 매뉴얼 제공

info 명령어 사용방법, 옵션 등 제공

whatis 명령어 기능 간략히

manpath `man`페이지의 위치 경로를 검색하여 표시

whereis 명령어의 실행파일 절대경로와 소스코드, 설정파일, 매뉴얼페이지를 찾아 출력

apropos `man`페이지 설명에서 지정한 키워드를 포함하고 있는 명령어

#### 사용자 생성 명령어

`su` (switch user/substitute user)의 줄임말, 다른 사용자 계정 로그인

`useradd` 계정 생성 명령어

`passwd` 계정 패스워드 입력 및 변경

#### 사용자 관련 파일

/etc/default/useradd 사용자 계정 추가 시, 기본 설정 정보 저장된 파일

/etc/passwd 사용자 정보가 있는 파일, 사용자가 로그인할 때 사용됨

/etc/shadow 사용자 패스워드 정보가 암호화되어 있는 파일

/etc/login.defs 사용자 계정 설정과 관련된 기본값을 정의한 파일

#### 사용자 계정 관리

`usermod` 사용자 정보 변경

`userdel` 계정 정보 삭제

change 패스워드 만료 정보 변경

#### 그룹 관리

`/etc/group` 그룹이 정의되어 있는 파일

groupdel 그룹 삭제

### 프로세스 관리

#### 프로세스의 유형

포어그라운드 프로세스 : 눈에 보임, 병렬 작업 안됨 → `sleep` 5

백그라운드 프로세스 : 눈에 안보임, 병렬 작업 됨 & → `sleep` 5 &

fork( ) : 새로운 프로세스를 만들 때 기존 프로세스를 복제하는 방식, 새 프로세스의 메모리 할당o

exec( ) : 호출하는 프로세스가 새로운 프로세스로 변경되는 방식, 새 프로세스의 메모리 할당x

데몬(Daemon) : 리눅스 시스템이 부팅 시 자동으로 실행되는 백그라운드 프로세스, 대기 중인 서버 프로세스

| 데몬 종류 | 설명 | 관련 서비스 |
| --- | --- | --- |
| standalone 데몬 | 특정 서비스 프로그램 | http, mysql, nameserver, sendmail |
| inetd 데몬 (슈퍼 데몬) | 다른 데몬들의 상위에 존재하는 standalone 데몬 |  |
| inetd 타입 데몬 | 직접 서비스를 실행 못하고 inetd 데몬을 통해서 실행 | telnet, ftp, rlogin |

시그널(Signal) : 프로세스에 이벤트 발생을 전달해주는 소프트웨어 인터럽트, `kill -l`로 시그널 리스트 확인 가능

| 번호 | 시그널 | 발생 조건 | 기본 동작 |
| --- | --- | --- | --- |
| 1 | SIGHUP | 터미널과 연결이 끊어졌을 때 | 종료 후 재시작 |
| 2 | SIGINT | ctrl + c 입력 | 종료 |
| 3 | SIGQUIT | ctrl + \ 입력 | 코어덤프 |
| 9 | SIGKILL | 프로세스 강제 종료 시 | 종료 |
| 15 | SIGTERM | kill 시스템 호출 시 | 종료 |
| 19 | SIGSTOP | SIGCONT 시그널을 받을 때까지 | 종료 |
| 20 | SIGTSTP | ctrl + z 입력 | 프로세스 대기로 전환 |
